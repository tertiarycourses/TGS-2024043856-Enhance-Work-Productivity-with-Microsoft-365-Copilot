# Northstar Microsoft 365 Agent Staff Enablement Plan

## Roles
- Agent owner maintains instructions, knowledge and tests.
- Knowledge owner approves content and permissions.
- Supervisor reviews proposed operational interpretations.
- Users retrieve information and report defects; agent output is not approval.

## Learning route
1. Explain purpose, fixed snapshot and permission boundary.
2. Demonstrate a cited answer and an UNKNOWN response.
3. Practise the eight retrieval and boundary tests.
4. Use Microsoft Loop to record owner, test, evidence, defect and retest.
5. Share only with named users who already have source access.

## Transition and support
Pilot privately, test with named users, correct failures, then request controlled sharing. Preserve the previous configuration and test log for rollback. Review monthly or whenever instructions, knowledge or tenant policy changes.

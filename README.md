# Enhance Work Productivity with Microsoft 365 Copilot

**Course code:** TGS-2024043856  
**Duration:** 2 days / 16 hours  
**Provider:** Tertiary Infotech Academy Pte Ltd (UEN 201200696W)

This repository contains the learner-facing courseware for the WSQ course **Enhance Work Productivity with Microsoft 365 Copilot**. It follows one connected fictional company scenario, Lumina Living Pte Ltd, through sixteen progressive activities spanning Microsoft 365 Copilot Chat, Word, PowerPoint, Excel, Outlook, Teams, Loop and Microsoft 365 Copilot agents.

## Package

- `courseware/` — current slide deck, Learner Guide and Lesson Plan
- `activities/` — sixteen self-contained activity folders; every activity includes an Excel workbook
- `activities/README.md` — activity sequence and evidence map

Detailed click-by-click procedures and complete prompts are in the Learner Guide and activity folders. The slide deck is deliberately visual and concept-led.

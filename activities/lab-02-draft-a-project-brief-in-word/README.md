# Lab 02: Draft a Project Brief in Word from Excel Evidence

**Topic 01** · **Foundation** · **Word + Excel + Copilot** · **K1 · A1**

## Goal

Turn a structured campaign register into a concise Word project brief without inventing scope or dates.

## Expected output

Two-page launch brief with cited objectives, milestones, risks and open questions.

## Files

- `Lumina-Living-Lab-02.xlsx` — learner starter and control workbook
- `completed/Lumina-Living-Lab-02-completed.xlsx` — completed comparison copy
- `LAB-02-Instructions.pdf` — printable detailed guide
- Other Office files in this folder are specific to this lab

## Primary prompt

> Draft a two-page project brief for Lumina Living's Q4 Sustainable Workspace campaign. Use only the attached Campaign_Register workbook. Include purpose, measurable objectives, scope, milestones, roles, top risks and open questions. Mark missing information as [TO CONFIRM]. Use a confident, neutral business tone.

## Procedure

1. **Open the Campaign_Register workbook and filter Status to Active.**

   Check that the active rows reconcile to the Summary control.

2. **Open the supplied Word brief template.**

   Keep the headings and document metadata block.

3. **Attach or reference the workbook in Copilot for Word.**

   Use the file picker rather than copying confidential rows into a web-grounded chat.

4. **Create the first draft using the supplied prompt.**

   > Draft a two-page project brief for Lumina Living's Q4 Sustainable Workspace campaign. Use only the attached Campaign_Register workbook. Include purpose, measurable objectives, scope, milestones, roles, top risks and open questions. Mark missing information as [TO CONFIRM]. Use a confident, neutral business tone.

5. **Compare each date, owner and target with the workbook.**

   Highlight corrected facts in yellow during review, then remove highlighting after approval.

6. **Ask Copilot to tighten the executive summary to 120 words.**

   > Rewrite only the executive summary in no more than 120 words. Preserve every verified number and [TO CONFIRM] marker.

7. **Save the final brief and record the filename in the workbook Evidence_Register.**

   Do not overwrite the starter template.


## Acceptance test

The brief matches the workbook, contains no invented facts and retains [TO CONFIRM] markers for missing evidence.

## Evidence

- Completed workbook with Prompt_Log and Evidence_Register
- App-specific artifact and a credential-safe screenshot
- Verification, exception and human-approval note

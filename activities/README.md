# Activity Overview — Enhance Work Productivity with Microsoft 365 Copilot

**Course code:** TGS-2024043856  
**Version:** v8.0 · 15 August 2026

All sixteen activities use one Lumina Living Pte Ltd campaign scenario. Every folder is self-contained and includes an Excel workbook. Detailed procedures and full prompts are in the folder README/PDF and the Learner Guide.

| Lab | Day | Primary apps | Level | Output |
|---:|---:|---|---|---|
| 01 | 1 | Microsoft 365 Copilot Chat + Excel | Foundation | Completed setup, grounding and prompt-review register in Excel. |
| 02 | 1 | Word + Excel + Copilot | Foundation | Two-page launch brief with cited objectives, milestones, risks and open questions. |
| 03 | 1 | Word + Excel + Copilot | Intermediate | Approved policy draft, issue log and staff quick-reference checklist. |
| 04 | 1 | PowerPoint + Word + Excel + Copilot | Intermediate | Eight-slide leadership deck with one message per slide and a documented evidence map. |
| 05 | 1 | PowerPoint + Excel + Copilot | Intermediate | Polished deck with native trend, contribution and variance charts plus verified speaker notes. |
| 06 | 1 | Excel + Copilot | Foundation | Formula-driven campaign table with revenue, margin, conversion, status and error controls. |
| 07 | 1 | Excel + Copilot | Intermediate | Diagnostic workbook with KPI summary, segment analysis, anomaly log and management findings. |
| 08 | 1 | Excel + Analyst agent | Advanced | Forecast model with base, downside and upside scenarios, sensitivity table and decision guardrails. |
| 09 | 2 | Outlook + Excel + Copilot | Intermediate | Inbox triage register, verified thread summary and one approval-ready draft reply. |
| 10 | 2 | Teams + Excel + Copilot | Intermediate | Meeting brief, decision log, action register and reviewed follow-up message. |
| 11 | 2 | Loop + Teams + Excel + Copilot | Advanced | Loop workspace design, transition backlog, training matrix and adoption dashboard. |
| 12 | 2 | Microsoft 365 Copilot agents + Excel | Foundation Agent | Agent design canvas, knowledge register, risk controls and ten acceptance tests. |
| 13 | 2 | Copilot Studio / Agent Builder + Excel | Intermediate Agent | Working intake agent, controlled instructions, knowledge source and routed test results. |
| 14 | 2 | Copilot Studio + Power Automate + Excel | Advanced Agent | Agent-to-queue flow with validation, approval state, response ID and run audit. |
| 15 | 2 | Microsoft 365 Copilot + Analyst + PowerPoint + Excel | Advanced Pipeline | Three-stage pipeline specification, analysis workbook, chart-led decision deck and approval log. |
| 16 | 2 | Microsoft 365 Copilot agents + Outlook + Teams + Excel | Capstone Pipeline | End-to-end pilot run, approved Outlook draft, Teams handover, monitoring dashboard and staff training plan. |

## Progression

- Labs 01–05: safe prompting, Word and PowerPoint evidence stories.
- Labs 06–08: formula generation, deep diagnostic analysis, forecasting and scenarios in Excel.
- Labs 09–11: Outlook, Teams and Loop collaboration with human review.
- Labs 12–16: scoped agent design, controlled actions and a governed end-to-end pipeline.
